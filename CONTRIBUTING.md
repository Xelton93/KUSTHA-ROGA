# Contributing

1. Open an issue before large changes.
2. Every new or edited fact needs a source in `data/references.csv` (text, chapter, edition).
3. Paraphrase classical passages; do not paste long text from copyrighted editions or commentaries.
4. Mark modern correlations `(proposed)` unless backed by a published citation.
5. Run `python3 scripts/validate.py` before opening a pull request.
6. Record disagreements between Samhitas as separate entries; do not silently overwrite.
